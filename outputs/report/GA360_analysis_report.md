# GA360 电商漏斗与用户生命周期分析报告

> 本报告由主 Notebook `notebooks/GA360_ecommerce_analysis.ipynb` 生成，配套 Tableau 公共看板。
> 分析对象：Google Merchandise Store（GA360 Sample）｜ 观察期：2016-08-01 ~ 2017-08-01

## 核心结论速览

- 全站 UV 714,167，Session 903,653，Session 购买率 **1.28%**，总收入 **$1,540,071.24**。
- **最大流失在「浏览→加购」（64.5%）**，而非支付环节——优化优先级是商品详情页与加购引导。
- **Referral 是利润中心**（11.6% 流量贡献 42.3% 收入，购买率 5.08%）；**Social 大流量低价值**（25% 流量仅 0.3% 收入）。
- **回访用户转化是新用户 3.1 倍**（13.23% vs 4.28%）；**高价值用户 3.8% 人数贡献 25.2% 收入**，人均 6.57 倍。
- **复合洞察**：高价值用户几乎全部集中在 `Referral × desktop × 新用户`；渠道决定"买不买"、新老决定"买多少"、设备是放大器。
